# Direction

Subject: source control built for coding agents, for tech leads of small teams (2 to 20 people) that run many agents.
Job: say it's a Git server you run on your own Cloudflare account, and show one commit reaching the API, plain git and GitHub.
Kept: "one commit, three places": a type-led headline over three panes (API call, `git pull`, the GitHub copy) tied by the same lime-highlighted commit id; it shows the product's promise at a glance. Also tried: the split hero with a terminal transcript (the previous page), which had to be read to get the point.
References: Apple Continuity (the same document on four devices implies sync without arrows); Wise (the live transaction in the hero, real values, a proof line); Teenage Engineering (the object on a plain ground, small mono labels, one signal color). In the category, dark grounds with glows and "X for the agentic era" headlines are the default; lime and a light paper ground are unclaimed.

## Materials
- Type: Instrument Sans for everything people read (600 for headings, set tight); JetBrains Mono for code, commit ids, commands and labels.
- Palette: light ground #fafaf7 (paper) and dark ground #0d0e0b (green-black night); ink #151711 / #edefea; one accent, lime #c4f252, always a fill with dark ink on it; neutrals tinted toward the lime hue; teal success, red danger, diff green and red only inside code. All roles live in shared/ui/theme.css.
- Shape: radius 4 (chips), 8 (controls), 12 (panes and cards); 1px hairlines; surfaces separate by a line on light and by lightness on dark; no shadows, blur or gradients.
- Imagery: the product drawn in HTML: API requests, terminal output, a GitHub commit list, with realistic values. No illustrations or stock. The demo video replaces the hero strip when it exists.
- Signature: a commit id in mono on the lime highlight, for the one commit the reader should follow. The logo's lime node is the same idea: the newest commit.
- Voice: plain, specific, honest about status (planned features never in the present tense). Errors and money: plain and calm.
- Density and pace: persuade pages comfortable (body 17 to 19px, display 44 to 92px), instant hovers, only the button press animates (100ms); app screens later compact (14 to 16px), quiet.

## Standard
Layout, navigation, controls and states follow the platform and Critly's concepts.
