Two important comparisons. GitHub itself made stacked PRs generally available October 6. “Supports stacks” alone is no longer a reason to migrate.

Jujutsu snapshots changed work during most commands and supports multiple workspaces. Its Git backend preserves collaboration with Git users. It addresses local history friction, while a forge supplies reviews, issues, CI, and community.
