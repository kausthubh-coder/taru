What it fixes

Most of these were raised by developers like Theo (t3.gg) about Git and GitHub in agent-heavy teams. Two are only partly solved, and the list says so.

Private folders inside a public repo
The server decides who sees which folders. The GitHub copy leaves private folders out.
In-flight PRs and unreleased security fixes
Private until you publish them.
.env leaks and sharing secrets
Secrets are encrypted, never in history, and handed only to the people, agents and CI that need them. A push that contains a secret is blocked.
Agents need a full OS and a checkout to touch code
An agent API and MCP server: read, write and merge with no clone.
Worktree pain with parallel agents
No worktrees through the API. The CLI makes instant local workspaces.
Commits and branches as busywork
The CLI snapshots work automatically. Organize history later.
Merge queues that are slow and buggy
No merge queue. Tests run after the merge, and AI resolves conflicts.
Large files
Stored in R2, with no download fees.
Slow, flaky CI
Partly. CI stays on GitHub Actions through the copy, or runs on Depot or Buildkite directly. Failures go straight back to the agent.
GitHub outages
Partly. Serving your repo doesn't depend on GitHub, but then our uptime is our job.
Getting people to leave GitHub
They don't have to. The automatic copy keeps contributors, stars and CI where they are.

How it works

Git-compatible

Taru speaks Git's HTTP protocol, so git clone, git push and git fetch work with the client you already have. Nothing to install on a laptop.

The server does the heavy work

History, blame, commits, merges and rebases happen on the server, so an agent needs an API call, not a checkout. The idea comes from Anthropic's Scion, which replaced Git inside Anthropic.

Content-addressed storage on Cloudflare

Each file's contents are stored once, keyed by hash. A Durable Object per repository keeps refs, commits and small objects in SQLite, and large files go to R2.

The GitHub copy

Every push is mirrored to a GitHub repository you own, with private folders left out. Actions, contributors and stars stay where they are.

Open source. Runs on your own Cloudflare account.

Taru is AGPL-3.0. Deploy it to your own Cloudflare account and the code and the data stay yours.

It's free while you try it, on Cloudflare's free plan. Once a team uses it for real it costs about $5 a month, which is Cloudflare's paid Workers plan, not a Taru fee.
